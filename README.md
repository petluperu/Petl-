# PETLU — Código definitivo para publicar en una cuenta nueva de GitHub

## Instrucciones
1. Crea repositorio público nuevo, por ejemplo `Petlu`.
2. Sube **el contenido descomprimido** del ZIP: `index.html`, `script.js`, `styles.css`, `README.md` y carpeta `assets` directamente a la raíz.
3. Ve a **Settings > Pages > Deploy from a branch > main > / (root)** y guarda.
4. Espera a que termine la publicación en **Actions**. El enlace será `https://TU-USUARIO.github.io/Petlu/` (respetando mayúsculas).
5. Para evitar cargar una versión antigua, abre el sitio en una ventana privada o presiona Ctrl+Shift+R.
